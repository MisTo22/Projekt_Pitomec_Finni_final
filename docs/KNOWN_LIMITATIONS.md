# Известные ограничения промежуточной версии

1. Нет отдельного планировщика бюджета с распределением доступной суммы по обязательным расходам, желаниям и накоплениям.
2. Нет сравнения «план / факт» по завершённому периоду.
3. `periods.json` содержит 6 периодов, но текущая v2-логика `GameViewModel` рассчитывает утренний доход напрямую и не использует этот JSON как источник последовательной экономики.
4. `goals.json` содержит 4 цели, однако `GameState2` имеет фиксированную цель 180 монет; полноценного выбора цели из `goals.json` в текущей логике нет.
5. `products.json` содержит 10 позиций, но текущий UI использует встроенные `Wish` и `ShopItem` из `Content.kt`.
6. Нет операции снятия средств из накоплений с отдельным подтверждением.
7. Нет расчёта срока достижения цели.
8. Нет полноценной истории покупок/периодов.
9. Нет свободного ввода имени питомца.
10. Возрастная карта содержит группы 7–9 и 10–11, а интерфейс предлагает 7–8 и 9–11; перед финалом диапазоны следует унифицировать.
11. Физическое тестирование и release-сборка должны быть подтверждены командой перед финальной сдачей.
12. Лицензионные документы для всех сторонних визуальных/шрифтовых ресурсов следует собрать отдельно.
