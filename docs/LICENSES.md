# Сторонние библиотеки и ресурсы

## Программные зависимости

| Зависимость | Версия/источник | Назначение |
|---|---|---|
| AndroidX Core KTX | 1.13.1 | базовые Android API |
| Activity Compose | 1.9.3 | Compose Activity |
| Lifecycle ViewModel Compose | 2.8.7 | ViewModel |
| Jetpack Compose BOM | 2024.10.01 | версии Compose |
| Material 3 | через Compose BOM | UI |
| Gson | 2.11.0 | JSON и локальная сериализация |

Лицензионные тексты зависимостей следует хранить в соответствии с правилами выбранного способа распространения.

## Ресурсы проекта

- `res/font/nunito.ttf` — шрифт Nunito; необходимо сохранить подтверждение лицензии/условий распространения.
- PNG/JPG в `res/drawable-nodpi/` — игровые изображения; перед публикацией необходимо иметь подтверждение права команды на использование и распространение.
- SVG/vector drawable в `res/drawable/` — графические элементы проекта.
- `res/raw/click_sound.mp3` — звуковой ресурс; перед публикацией необходимо подтвердить права.

## Статус для промежуточной сдачи

Перечень сформирован по содержимому проекта. Отдельные лицензионные файлы для каждого ресурса в предоставленном архиве не были установлены как подтверждённые документы. Для финальной сдачи рекомендуется добавить ссылки/файлы лицензий и авторство в этот документ.
