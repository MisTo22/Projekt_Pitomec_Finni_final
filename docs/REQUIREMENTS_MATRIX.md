# Матрица соответствия ТЗ — промежуточная версия

Статусы:
- **Реализовано** — функция присутствует в коде и доступна через интерфейс.
- **Частично** — часть требования выполнена, но не весь объём.
- **В работе / финал** — функция не является частью текущей промежуточной реализации.

| Требование | Статус | Подтверждение |
|---|---|---|
| 2.5.1 Первый запуск и локальный профиль | Частично | Есть вход без регистрации и возраст; отдельного игрового имени питомца нет |
| 2.5.2 Создание питомца | Частично | Есть выбор возрастной группы и визуальный Финни; свободная настройка внешности/имени отсутствует |
| 2.5.3 Главный экран | Реализовано | Питомец, баланс, показатели, действия и навигация |
| 2.5.4 Игровая валюта | Реализовано | Старт, задания, ежедневное начисление, уровни |
| 2.5.5 Планирование бюджета | В работе / финал | Отдельного распределения бюджета и сравнения план/факт нет |
| 2.5.6 Покупки и расходы | Частично | Есть обязательные/желательные контексты, цены и блокировка при нехватке; нет отдельной истории покупок |
| 2.5.7 Накопления и цель | Частично | Есть цель и перевод денег в накопление; нет снятия и расчёта срока |
| 2.5.8 Финансовые задания | Реализовано | 9 заданий: 3 бюджет, 3 накопления, 3 покупки; есть правильный/ошибочный путь |
| 2.5.9 Последствия и обратная связь | Реализовано | После действий меняются баланс/показатели и показывается текстовая обратная связь |
| 2.5.10 Прогресс и развитие | Реализовано | 3 стадии, 3 состояния настроения, уровни и прогресс |
| 2.5.11 История и учебный прогресс | Частично | Хранятся solved, bought, day и прогресс; полноценной истории периодов нет |
| 2.5.12 Раздел взрослого | Реализовано | Арифметический барьер, статистика, сброс |
| 2.5.13 Сохранение состояния | Реализовано | SharedPreferences + Gson |
| 2.5.13 Демонстрационный режим | Частично | Переходы по игровым дням доступны через сон/пробуждение; отдельного флага demo mode нет |
| 2.5.14 Управление контентом | Реализовано | Задания v2 вынесены в `tasks_v2.json` |
| 2.6 6+ заданий | Реализовано | 9 заданий |
| 2.6 3 темы | Реализовано | budget / savings / purchases |
| 2.6 5 последовательных периодов | Контент есть | `periods.json` содержит 6 периодов, но текущая игровая логика v2 не использует его как источник экономики |
| 2.6 8 покупок | Реализовано по контенту | 10 позиций в `products.json`; UI v2 использует 4 желания + 3 действия заботы |
| 2.6 3 цели | Реализовано | 4 цели в `goals.json`; UI v2 в текущей реализации использует встроенную цель 180 |
| 2.6 3 стадии | Реализовано | Стадии определяются уровнем |
| 3.1 Android 8+ | Реализовано | minSdk 26 |
| 3.1 Портретная ориентация | Реализовано | `screenOrientation="portrait"` |
| 3.5 Без аккаунта и персональных данных | Реализовано | Локальный профиль, без сетевой регистрации |
| 3.5 Минимум разрешений | Реализовано | Дополнительных permissions нет |
| 3.6 UX для детей | Реализовано частично | Короткие тексты, крупные карточки; финальная accessibility-проверка требует физического устройства |
