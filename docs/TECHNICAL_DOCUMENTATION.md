# Техническая документация

## 1. Архитектура

Приложение построено как локальное Android-приложение без серверной части.

Основные компоненты:

### `MainActivity.kt`
Точка входа Android-приложения.

### `GameScreen.kt`
Основной Compose-интерфейс. Содержит:
- экран входа;
- выбор возраста;
- основной игровой экран;
- навигацию;
- экран желаний/покупок;
- экран заданий;
- режим взрослого;
- визуальные анимации и интерактивные элементы.

### `GameViewModel.kt`
Центральная игровая логика:
- состояние игры;
- баланс;
- действия ухода;
- покупки;
- задания;
- награды;
- сон/пробуждение;
- рост;
- сохранение;
- сброс.

### `Models.kt`
Модели `Task2`, `Wish`, `ShopItem`, `GameState2`.

### `Content.kt`
Загрузка заданий и статические игровые справочники.

Рабочие задания загружаются из:

`app/src/main/assets/json/tasks_v2.json`

### `SaveStore.kt`
Локальное сохранение через `SharedPreferences` и `Gson`.

### `SoundManager.kt`
Локальное управление звуком.

## 2. Состояние игры

`GameState2` содержит:

| Поле | Назначение |
|---|---|
| `coins` | доступные игровые монеты |
| `day` | номер игрового дня |
| `food` | сытость |
| `joy` | радость |
| `energy` | энергия |
| `level` | уровень Финни |
| `prog` | прогресс до следующего уровня |
| `saved` | накопленная сумма |
| `savedTarget` | цель накопления |
| `age` | возрастная группа |
| `solved` | решённые задания |
| `bought` | купленные желания |
| `sleeping` | состояние сна |

## 3. Сохранение

Ключи:
- SharedPreferences: `finny_save_v2`;
- запись состояния: `game_state_v2`.

При изменении состояния `GameViewModel.commit()` обновляет `StateFlow` и вызывает `SaveStore.save()`.

## 4. Игровая экономика

### Старт

Стартовый баланс — 25 монет.

### Ежедневное начисление

После пробуждения:
- базовая сумма: 5;
- случайная добавка: 0–3;
- бонус +2, если food, joy и energy не ниже 50.

Итого: от 5 до 10 монет.

### Задания

Первое правильное прохождение:
- +15 монет.

Повторное правильное прохождение:
- +2 монеты.

### Уровень

При достижении 100 единиц прогресса:
- прогресс уменьшается на 100;
- уровень увеличивается на 1;
- начисляется +20 монет.

### Забота

| Действие | Цена | Эффект |
|---|---:|---|
| Корм | 10 | сытость +15 |
| Медовая вкусняшка | 5 | радость +10 |
| Ягодные витамины | 10 | энергия +15 |

### Желания

| Желание | Цена |
|---|---:|
| Мячик-попрыгун | 10 |
| Гирлянда из звёздочек | 15 |
| Игра-головоломка | 20 |
| Оранжевая кепка | 15 |

### Накопление

Команда `depositToGoal()` переводит все доступные монеты либо сумму до остатка цели в накопления.

Текущая цель в `GameState2` — 180 монет.

## 5. Состояние питомца

Настроение рассчитывается по минимальному из food, joy и energy:

- `>= 65` — happy;
- `>= 35` — ok;
- `< 35` — sad.

Стадия определяется уровнем:

- 1–3 — стадия 1;
- 4–5 — стадия 2;
- 6+ — стадия 3.

Для каждой стадии есть happy/ok/sad и sleep-вариант.

## 6. Возрастная адаптация

Пользователь выбирает 7–8 или 9–11.

Задания имеют карту возрастной группы в `Content.ageMap`.

При отображении заданий сначала показываются задания соответствующей возрастной группы.

## 7. Разрешения и данные

`AndroidManifest.xml` не содержит дополнительных runtime-разрешений.

Приложение не использует:
- камеру;
- микрофон;
- геолокацию;
- контакты;
- Bluetooth;
- внешние аккаунты;
- серверную БД.

Основные игровые данные хранятся локально.

## 8. Контент

Рабочий набор заданий вынесен в JSON, поэтому контент можно расширять без изменения основной игровой модели, если сохраняется структура `Task2`.

## 9. Сборка

Параметры Android Gradle Plugin проекта:

- compileSdk 34;
- minSdk 26;
- targetSdk 34;
- Java 17;
- Kotlin JVM target 17.

Release build в текущем промежуточном комплекте не считается подтверждённым, пока команда не проверит его фактической сборкой на своей машине.
