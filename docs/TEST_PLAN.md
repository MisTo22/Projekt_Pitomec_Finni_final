# План тестирования — промежуточная версия

## Цель

Проверить основной пользовательский путь, корректность игровой экономики, сохранение и отсутствие блокирующих ошибок.

## Тест-кейсы

| ID | Проверка | Действия | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Первый запуск | Запустить приложение без сохранения | Показывается приветственный экран |
| TC-02 | Возраст | Нажать «Играть», выбрать возраст | Открывается игра, возраст сохраняется |
| TC-03 | Стартовый баланс | Открыть главный экран | Баланс 25 |
| TC-04 | Забота | Купить корм/вкусняшку/витамины при достаточном балансе | Баланс уменьшается, показатель меняется |
| TC-05 | Недостаток средств | Выполнить покупку при недостаточном балансе | Покупка не проводится, показывается объяснение |
| TC-06 | Желание | Купить желание | Баланс уменьшается, желание добавляется в bought |
| TC-07 | Задание: ошибка | Выбрать неправильный ответ | Денег не начисляется, показывается подсказка |
| TC-08 | Задание: успех | Выбрать правильный ответ впервые | +15 монет, задание попадает в solved |
| TC-09 | Повтор задания | Повторить решённое задание | +2 монеты |
| TC-10 | Накопление | Нажать накопление при наличии монет | Монеты переводятся в saved |
| TC-11 | Сон | Нажать «Спать», затем «Разбудить» | День увеличивается, начисляется утренний доход |
| TC-12 | Уровень | Накопить 100 прогресса | Уровень увеличивается, начисляется +20 |
| TC-13 | Настроение | Изменять показатели | Спрайт Финни меняется по порогам |
| TC-14 | Сохранение | Изменить состояние, закрыть и открыть приложение | Состояние восстановлено |
| TC-15 | Родительский режим | Открыть режим взрослого и решить 6×7 | Открывается статистика |
| TC-16 | Сброс | В режиме взрослого выбрать сброс и подтвердить | Локальный прогресс очищен |
| TC-17 | Офлайн | Отключить интернет и пройти игровой цикл | Основной сценарий продолжает работать |
| TC-18 | Возрастная сортировка | Выбрать разные возрастные группы | В списке сначала идут соответствующие задания |

## Фактический результат

В эту промежуточную документацию намеренно не внесены вымышленные результаты прохождения на физическом устройстве. После прогона команды рекомендуется добавить столбцы «Фактический результат», «Устройство», «Android», «Статус».

## Приоритет перед финалом

Особое внимание:
- release APK;
- физическое устройство с RAM ≥3 ГБ;
- длительный сценарий с сохранением;
- отсутствие падений;
- accessibility;
- соответствие плану демонстрации.
