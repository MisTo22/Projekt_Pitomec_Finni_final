# «Питомец Финни» v2 — Android-проект (Kotlin + Jetpack Compose)

Точный порт последнего HTML-варианта `finni_v2.html` (дизайн макетов Group 6/7/8)
в нативное Android-приложение + новая сбалансированная экономика.

## Как открыть и запустить
1. Android Studio (Hedgehog 2023.1.1+) → **File → Open** → эта папка (`finni_android`).
2. Дождаться синхронизации Gradle (JDK 17: Settings → Build Tools → Gradle → Gradle JDK = 17).
3. Run ▶ на устройстве/эмуляторе Android 8.0+ (minSdk 26). Интернет приложению не нужен.

## Экраны (точь-в-точь finni_v2.html)
1. **Вход:** фиолетовый градиент, Финни (дышит), «Привет! Я Финни!», кнопка «▶ Играть»
   (при нажатии сжимается и становится фиолетовой).
2. **Возраст:** «Сколько тебе лет?» → кнопки **7–8 / 9–11**; выбор сортирует задания
   по возрастной группе и сохраняется в профиле.
3. **Дом:** фиолетовая панель (шапка + монета, карточка «Юный исследователь» с прогрессом
   и уровнем), далее на весь экран фон комнаты; поверх — три шкалы-карточки
   (Сытость/Радость/Энергия с градиентными плитками), пузырь-реплика по центру над ежом,
   белый круг с аватаром и тенью, жёлтый бейдж настроения, панель «Покормить / Играть / Спать».
   Сон: фон меняется на спальню с кроваткой, спящий спрайт, контурные «луны»; «Разбудить» = утро.
4. **Желания:** градиентная шапка, жёлтая карточка «КОПЛЮ НА Рюкзак исследователя 120/180»,
   сегменты Желания / Покупки / Задания, сетка желаний с ценами, сетка заботы, карточка «Задания на сегодня».
5. **Задания:** 9 карточек финграмотности (сортировка по возрасту), детали с вариантами,
   подсказкой/объяснением, наградой +15 (повтор +2).
6. **Низ:** навигация Дом / Желания / Задания — контурные иконки без заливки (обводка 2.7),
   активная — лавандовая пилюля.

## Анимации и взаимодействия (как в HTML)
- Нажатие любых кнопок/карточек: сжатие 0.92–0.95 + смена градиента на фиолетовый (`PressBox`).
- Ёж: дыхание в покое, прыжок/жевание/покачивание по действиям и idle; зоны касания
  (голова/пузо/лапки) и гладилка пальцем (drag).
- Частицы при тапах/наградах — **контурные фигурки в стиле иконок** (сердце, звезда, монета,
  луна, цветок, мяч, яблоко, молния): векторы `res/drawable/p_*.xml`, полёт вверх с затуханием.
- Пузырь-реплика: появление с scale/fade, перенос строк, по центру над ежом; idle-реплики каждые ~9 с.

## Экономика v2 (смысл заданий возвращён)
| Параметр | Значение | Идея |
|---|---|---|
| Старт | **25 монет** | хватает на 2–3 покупки заботы, но не «на всё» |
| Утро (пробуждение) | **+5…10**: база 5 + случайные 0–3 + **бонус +2**, если все шкалы ≥ 50 | забота вознаграждается, день имеет цену |
| Задания | **+15** впервые, **+2** повтор | основной доход → мотивация учиться |
| Уровень | **+20** при заполнении прогресса | редкая, но заметная награда |
| Траты | забота 5–10, желания 10–20 | монеты снова чего-то стоят |
| Износ шкал за день | сытость −12, радость −10, энергия +40 от сна | утро требует заботы |

Уровень стартует с **1** (прогресс 0); стадии ежа: 1–3 ур → малыш, 4–5 → подросший, 6+ → взрослый.

## Структура
```
app/src/main/
├── assets/json/tasks_v2.json        # 9 заданий v2 (тексты как в HTML)
├── res/drawable-nodpi/              # tile_*.png (18 градиентных плиток), finny_*.png (12 спрайтов),
│                                    # finny_lamp.png, room_day.jpg / room_night.jpg
├── res/drawable/                    # v_home/v_heart/v_list (навигация), p_*.xml (частицы-контурки)
├── res/font/nunito.ttf              # Nunito (вариативный, кириллица)
└── java/ru/finny/app/
    ├── MainActivity.kt
    ├── data/    Models.kt (GameState2/Task2/Wish/ShopItem), Content.kt (json+плитки+спрайты+AGE-карта),
    │            SaveStore.kt (SharedPreferences+Gson, офлайн-профиль)
    ├── game/    GameViewModel.kt (вся логика: действия, сон/утро, задания, уровень, idle, частицы)
    └── ui/      theme/ (палитра, Nunito, MaterialTheme), game/GameScreen.kt (все экраны, PressBox, навигация)
```

## Правки контента
- Задания — `assets/json/tasks_v2.json`; желания/покупки/плитки — `Content.kt`.
- Экономика (цены, награды, карманные) — `GameViewModel.kt` (константы в действиях и `wake()`).
- Палитра/градиенты — `ui/theme/Color.kt` (`gViolet`, `gOrange`, `gYellow`, `gPress`).
