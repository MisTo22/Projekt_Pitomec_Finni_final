# Питомец Финни — Android-прототип v2

## Статус

**Промежуточная версия для конкурсной сдачи.**

Документация описывает фактическое состояние предоставленной сборки и не предполагает, что функции, запланированные для финального этапа, уже реализованы.

## Назначение

«Питомец Финни» — локальное Android-приложение в игровом формате для знакомства детей 7–11 лет с базовыми финансовыми навыками.

Игровой цикл связывает:
- получение игровой валюты;
- обязательные и желательные траты;
- задания по финансовой грамотности;
- накопление на понятную цель;
- заботу о виртуальном питомце;
- изменение уровня и стадии развития Финни.

## Запуск

1. Открыть папку `finni_android` в Android Studio Hedgehog 2023.1.1+.
2. Использовать JDK 17.
3. Дождаться Gradle Sync.
4. Запустить на эмуляторе или физическом устройстве Android 8.0+.

Debug-сборка:

```bash
./gradlew assembleDebug
```

Windows:

```bat
gradlew.bat assembleDebug
```

Для финальной сдачи release APK должен быть собран и подписан отдельно.

## Основные экраны

1. Первый запуск — знакомство с Финни.
2. Выбор возраста — 7–8 или 9–11.
3. Дом — питомец, баланс, три показателя состояния и действия.
4. Желания/покупки — цели, желания, забота и переход к заданиям.
5. Задания — 9 финансовых ситуаций.
6. Раздел взрослого — статистика и сброс локального прогресса.

## Контент промежуточной версии

- 9 финансовых заданий;
- 3 темы: бюджет, накопления, покупки;
- 4 цели;
- 6 игровых периодов;
- 10 товарных позиций в демонстрационном контенте;
- 3 стадии развития Финни;
- 9 комбинаций стадии и настроения + 3 состояния сна.

## Сохранение и приватность

Профиль является локальным и гостевым. Реальные имя, телефон, e-mail, банковские реквизиты и другие реальные финансовые данные не запрашиваются.

Состояние сохраняется через `SharedPreferences` с сериализацией `Gson`.

Android-разрешения в `AndroidManifest.xml` не объявлены.

## Важное ограничение промежуточной версии

В этой версии нет отдельного интерфейса планирования бюджета с распределением суммы по обязательным/необязательным расходам/накоплениям и отдельного сравнения «план/факт». Поэтому в матрице требований эти пункты отмечены как находящиеся в работе или ожидающие финальной доработки.

Также текущая версия не реализует отдельное снятие средств из накоплений и расчёт срока достижения цели.

Эти ограничения намеренно зафиксированы для прозрачной промежуточной проверки.
